# K1 Demo Kiosk web UI

The demo page shown on a K1 kiosk by the K1 Demo Kiosk app. It drives the real coin and bill
acceptors, QR reader and camera through `kiosk.js`, and fakes everything else. **Demo only.**

- Open it in any browser to try it: a mock panel stands in for the hardware.
- On the kiosk: Back button → settings → GitHub Pages (or type this site's URL).
- Building a new demo? See [CLAUDE.md](CLAUDE.md) for the `kiosk.js` API and the rules.

`kiosk.js` comes from the K1DemoKiosk app repo; update it there and copy it here.
